# LTPS: Learning Transferable Policies through Shared Semantic Concepts

Project website: https://ltps-game.github.io/

Static HTML, CSS, and JavaScript with selected gameplay clips from the 4B and 0.8B models.

## Editing

- `content.js`: project text, contact details, and paper/code links.
- `highlights.js`: gameplay clip list.
- `assets/images/method.png`: method figure.
- `styles.css`: presentation and responsive layout.

No build step is required. GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps the site as plain static files.
