Abstract

Transferring experience to new environments is a central challenge for interactive agents. We introduce LTPS, a framework for learning transferable policies through shared state, task, and action concepts. Through joint concept learning and action prediction, a vision-language model learns to interpret visual observations and select semantic actions. A reusable skill library then executes these actions, allowing the same policy to operate across environments with lightweight skill adaptation.
